# MetaChat Tutor

Django web app for linguodidactics research — teaches constructive communication
roles, tactics and metagrapheme use in online polylogues. See `README.md`.

## Agent skills

### Issue tracker

Issues and specs live in GitHub issues, driven by the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default triage labels are used as-is. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout: `GLOSSARY.md` at the root, ADRs in `docs/adr/`. See `docs/agents/domain.md`.
