📋 What we collect and why

What is This Chatbot

MetaChat Tutor is a research instrument: it gives an opportunity to write messages and comments on behalf of constructive communication roles in online group discussions and records how the users of this chatbot perform.

Data from the Start Page

Filling out the information on the start page (your name, group, and your self-assessed language level) opens the session and identifies the user's research record. No account, e-mail, or password is required.

Replies to the Tasks in the Chatbot

The data we collect include: every message a user sends, the tutor's replies to the user's messages, pre-test and post-test answers with their scores, and the completion status of each task with timestamps. All data entries are linked to the state in which they were produced.

Data Export and Reset Function

The export button downloads this session as a single JSON file named after its session ID to the user's device. Using the "Reset" function erases the browser copy of the session, but the research record on the server is retained, as this data constitutes the core measurement for our study.

Who Analyzes the Collected Data and Why

The research team behind MetaChat Tutor uses this data solely to analyze linguodidactic outcomes inside the study held in BSUFL. Names are used only to link learners to their respective cohorts and are never published.
